# 数据导入说明

## Excel文件格式说明

### 必需列
- **文物名称** 或 **名称**: 文物的名称
- **分类** 或 **类别**: 文物所属分类（如：陶瓷、书画、玉器等）
- **年代**: 文物的年代（如：清代、明代、唐等）
- **描述** 或 **简介**: 文物的详细描述

### 可选列
- **颜色**: 文物的颜色（如：红色、金色、蓝色等）
- **材质**: 文物材质（如：陶瓷、丝绸、青铜等）
- **尺寸**: 文物尺寸（如：长20cm，宽15cm）
- **收藏编号** 或 **编号**: 文物的收藏编号
- **图片** 或 **图片路径**: 图片文件名或路径

## 使用步骤

### 1. 准备Excel文件
按照上述格式创建Excel文件，保存为 `.xlsx` 格式

### 2. 准备图片文件
将所有图片放在同一个目录下

### 3. 执行导入命令

```bash
python manage.py import_artifacts data.xlsx --image-dir /path/to/images
```

参数说明：
- `data.xlsx`: Excel文件路径
- `--image-dir`: 图片文件目录路径（可选）

### 4. 导入结果

导入成功后会显示：
- 总行数
- 成功导入数量
- 跳过数量（已存在或数据不完整）
- 错误数量

## 注意事项

1. **数据完整性**: 确保必需列都有数据，缺少文物名称的行会被跳过
2. **图片格式**: 支持常见图片格式（JPG、PNG、GIF等）
3. **重复数据**: 根据收藏编号判断是否重复，重复的文物不会被导入
4. **分类自动创建**: 如果分类不存在，会自动创建新分类
5. **字符编码**: 确保Excel文件使用UTF-8编码，避免中文乱码

## 导出示例

导出当前所有文物数据：

```bash
python manage.py export_artifacts output.xlsx
```

导出包含图片路径的完整数据：

```bash
python manage.py export_artifacts output.xlsx --include-images
```

## 常见问题

### Q: 导入失败提示"读取Excel文件失败"
A: 检查：
- Excel文件路径是否正确
- Excel文件格式是否为.xlsx
- 是否已安装openpyxl库

### Q: 图片无法上传
A: 检查：
- 图片目录路径是否正确
- 图片文件名与Excel中的是否一致
- 图片文件是否存在
- Django的MEDIA_ROOT配置是否正确

### Q: 中文乱码
A: 确保Excel文件保存时使用UTF-8编码

### Q: 重复数据如何处理
A: 系统会根据"收藏编号"判断重复，如需更新，请先删除或修改编号后再导入
