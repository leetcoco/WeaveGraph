## 📝 关键改进技术细节

### 避免识别周围区域的策略

```python
# 1. 提高面积阈值
threshold_area = max_area * 0.4  # 只保留大面积轮廓

# 2. 限制轮廓数量
valid_contours = sorted(valid_contours, key=cv2.contourArea, reverse=True)
valid_contours = valid_contours[:2]  # 最多2个

# 3. 减小膨胀
kernel2 = np.ones((3, 3), np.uint8)  # 最小kernel
mask = cv2.dilate(mask, kernel2, iterations=1)

# 4. 减小羽化
mask_smooth = cv2.GaussianBlur(mask, (5, 5), 1)  # 最小羽化

# 5. 提高Canny阈值
edges = cv2.Canny(gray, 50, 120)  # 减少噪声
```
