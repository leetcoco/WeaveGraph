# V8映射在网页上的验证步骤

## 📋 前提条件

- 服务器已启动：`python manage.py runserver`
- 访问页面：`http://127.0.0.1:8000/fashion/`

## ✅ 验证步骤

### 1. 强制清除缓存并刷新
1. 打开浏览器（Chrome/Edge/Firefox）
2. 按 `Ctrl + Shift + Delete` (Chrome) 或 `Ctrl + F5` (Edge)
3. 勾选"缓存的图片和文件"
4. 点击"清除数据"或"清除缓存"
5. 重新访问：`http://127.0.0.1:8000/fashion/`

### 2. 打开浏览器开发者工具
1. 按 `F12` 打开开发者工具
2. 切换到"Console"（控制台）标签
3. 刷新页面 (`F5`)

### 3. 查看控制台日志

**正常情况下应该看到**：
```
=== V8 updateDesignPreview 被调用 ===
selectedGarmentType: {id: ..., name: "...", ...}
selectedArtifactImage: HTMLImageElement
更新预览: ... 性别: ...
=== 服装图片加载成功 ===
服装图片尺寸: 256 x 256
=== 开始V8映射 ===
V8 Mask创建完成，覆盖率计算中...
=== V8映射完成 ===
```

**如果没有看到这些日志**，说明V8代码没有执行。

### 4. 查看Canvas版本标识
1. 选择任意一幅画作
2. 选择任意一件服装（建议：宋褙子（男）或旗袍）
3. 查看画布右下角
4. **应该看到**：红色的"V8.0"字样

### 5. 验证效果

#### 测试宋褙子（男）
- ✅ 周围应该没有色块
- ✅ 边界应该精确
- ✅ 覆盖率应该约42.8%（比v7的60.6%低）

#### 测试旗袍
- ✅ 圆领应该保持圆弧形，不应该变成长方形
- ✅ 细节应该完整保留
- ✅ 覆盖率应该约17.1%

## 🐛 故障排除

### 问题1：控制台报错"createGarmentMaskV8 is not defined"
**原因**：V8函数没有加载
**解决**：
1. 检查design.html文件中是否有createGarmentMaskV8函数
2. 确保函数在updateDesignPreview函数之前定义

### 问题2：图片加载失败（CORS错误）
**原因**：跨域问题
**解决**：
1. 检查static文件路径是否正确
2. 确认Django的STATIC_URL配置
3. 检查浏览器控制台的Network标签，查看图片加载状态

### 问题3：效果还是旧的multiply模式
**原因**：
1. 浏览器缓存了旧版本
2. JavaScript没有执行到V8代码

**解决**：
1. 完全清除浏览器缓存
2. 尝试使用隐身/无痕模式
3. 检查控制台是否有JavaScript错误

### 问题4：Canvas没有显示"V8.0"标识
**原因**：页面没有更新到最新版本
**解决**：
1. 确认服务器检测到文件变化（Django会自动重载）
2. 完全清除缓存
3. 硬刷新：`Ctrl + Shift + R`

| 羽化核 | 5×5, σ=1 | **3×3, σ=0.5** | 保持细节 ✅ |
| 缩放倍数 | 1.3 | **1.02** | 恰到好处 ✅ |
| 轮廓过滤 | 无 | **40%阈值** | 精确边界 ✅ |

## 🎯 成功标志

如果看到以下所有标志，说明V8已成功集成：

1. ✅ 控制台显示V8日志
2. ✅ Canvas右下角有"V8.0"标识
3. ✅ 宋褙子（男）周围无色块
4. ✅ 旗袍圆领保持圆形
5. ✅ 整体效果与v8_test.py生成的结果一致

## 🆘 如果还是不行

1. 访问V8结果展示页确认效果：
   - `http://127.0.0.1:8000/fashion/v8-results/`
   
2. 如果v8-results页面正常，说明：
   - V8逻辑本身是正确的
   - 图片路径是正确的
   - 问题出在design.html的集成上

3. 如果v8-results页面也无法访问：
   - 检查图片文件是否复制到media目录
   - 检查Django的MEDIA_URL配置
