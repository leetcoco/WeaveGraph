# 服装分类模型 - 重要说明

## 当前问题

模型的准确率很低（12-35%），原因是：**训练标签是基于颜色规则自动生成的假数据**，不是真实的人工标注。

## 为什么准确率低？

1. **假标签问题**：训练脚本使用`generate_garment_label_based_on_color()`函数，根据画作的调色板颜色自动分配服装类型。这些标签不是真实的，模型学不到有用的模式。

2. **随机性**：即使是同一个文物，每次运行训练脚本，标签可能不同（因为使用了random.choice）。

3. **数据不平衡**：某些服装类型样本很少，导致模型偏向预测数量多的类别。

不做分类，只使用预训练模型提取图像特征，然后基于颜色、风格等规则推荐服装。

### 方案3：小样本学习

使用少量真实标注数据，通过迁移学习快速训练模型。

## 建议

为了获得真实的预测效果，建议：

1. **创建真实标注数据集**
   - 选择50-100幅有代表性的文物
   - 为每幅画手动选择最合适的1-2种服装
   - 使用这些真实数据训练模型

2. **使用迁移学习**
   - 基于少量标注数据（如50个样本）
   - 使用预训练ResNet进行微调
   - 可以获得较好的效果

3. **结合规则和模型**
   - 使用颜色规则作为初始推荐
   - 用模型进行验证和优化
   - 提供可调节的参数

## 注意

**当前所有训练脚本都使用假标签，训练出来的模型无法进行真实预测。**

要获得真实的服装推荐系统，必须有真实的人工标注数据。
